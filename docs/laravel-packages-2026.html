🐳 Laravel Sail — PHP 8.4 / 8.5 (mín. 8.3 en Laravel 13)
Docker
laravel/sail
Sail · runtimes PHP 8.3 → 8.5
Entorno Docker local sin instalar PHP en tu máquina. Solo necesitas Docker Desktop. Laravel 13 requiere PHP 8.3 como mínimo.
Crear proyecto nuevo Laravel 13 (con servicios)
curl -s "https://laravel.build/myapp?with=mysql,redis" | bash cd myapp && ./vendor/bin/sail up -d
Crear con starter kit Vue 3.5 + Inertia 3 + TypeScript
# El instalador oficial scaffolda Vue 3.5 + Inertia 3 + Tailwind v4 + TypeScript laravel new myapp --vue # o de forma interactiva (este stack usa siempre Vue): laravel new myapp cd myapp && ./vendor/bin/sail up -d
Agregar Sail a proyecto existente (con PHP local)
composer require laravel/sail --dev php artisan sail:install ./vendor/bin/sail up -d
Agregar Sail sin PHP local (solo Docker)
docker run --rm \ -u "$(id -u):$(id -g)" \ -v "$(pwd)":/var/www/html \ -w /var/www/html \ laravelsail/php84-composer:latest \ composer install
Cambiar a PHP 8.5 — docker-compose.yml
# En docker-compose.yml, busca: laravel.test: build: context: ./vendor/laravel/sail/runtimes/8.4 # Cambia a: context: ./vendor/laravel/sail/runtimes/8.5 dockerfile: Dockerfile args: WWWGROUP: '${WWWGROUP}' image: sail-8.5/app
Reconstruir y levantar
./vendor/bin/sail build --no-cache ./vendor/bin/sail up -d
Alias conveniente — agregar a ~/.bashrc
alias sail='[ -f sail ] && bash sail || bash vendor/bin/sail'
Comandos esenciales
./vendor/bin/sail artisan migrate ./vendor/bin/sail composer require package/name ./vendor/bin/sail npm run dev ./vendor/bin/sail php --version ./vendor/bin/sail shell # bash dentro del container ./vendor/bin/sail artisan reverb:start ./vendor/bin/sail artisan horizon
✅ Laravel 13 salió el 17 de marzo de 2026 (GA, anunciado en Laracon EU 2026). Cero breaking changes desde Laravel 12; el único requisito nuevo es PHP 8.3 mínimo. Laravel 12 recibe bugfixes hasta agosto 2026 y seguridad hasta febrero 2027.
💡 PHP 8.4 es la opción por defecto en la mayoría de hosts. PHP 8.5 (GA nov 2025) es ideal para proyectos nuevos: pipe operator |>, clone with, URI parser nativo, array_first() / array_last(). Ambas son compatibles con Laravel 13.

Auth Headless

Fortify ^1.x · OTP ^1.0
Stack auth 100% headless — sin UI incluida. Cubre: login, registro, reset password, verificación email, 2FA TOTP, OTP por email/SMS y passkeys (nativo en Laravel 13).
① Laravel Fortify — Backend headless
1. Instalar
./vendor/bin/sail composer require laravel/fortify
2. Publish + Migrate
./vendor/bin/sail artisan vendor:publish --provider="Laravel\Fortify\FortifyServiceProvider" ./vendor/bin/sail artisan migrate
3. Registrar en bootstrap/providers.php
return [ App\Providers\AppServiceProvider::class, App\Providers\FortifyServiceProvider::class, // ← agregar ];
4. config/fortify.php — activar features
'features' => [ Features::registration(), Features::resetPasswords(), Features::emailVerification(), Features::updateProfileInformation(), Features::updatePasswords(), Features::twoFactorAuthentication([ 'confirm' => true, 'confirmPassword' => true, ]), ],
5. FortifyServiceProvider — responses para SPA/Inertia
use Laravel\Fortify\Fortify; use Laravel\Fortify\Contracts\LoginResponse; public function boot(): void { $this->app->instance(LoginResponse::class, new class implements LoginResponse { public function toResponse($request) { return $request->wantsJson() ? response()->json(['redirect' => '/dashboard']) : redirect()->intended('/dashboard'); } } ); Fortify::authenticateUsing(function (Request $request) { $user = \App\Models\User ::where('email', $request->email)->first(); if ($user && \Hash::check($request->password, $user->password)) { return $user; } }); }
6. Rutas que Fortify registra automáticamente
POST /login ← login con email+password POST /logout ← logout POST /register ← registro POST /forgot-password ← solicitar link de reset POST /reset-password ← cambiar contraseña GET /email/verify/{id}/{hash} ← verificar email POST /email/verification-notification ← reenviar verificación POST /two-factor-challenge ← verificar código 2FA TOTP POST /user/two-factor-authentication ← activar 2FA DELETE /user/two-factor-authentication ← desactivar 2FA GET /user/two-factor-qr-code ← QR para Google Authenticator GET /user/two-factor-recovery-codes ← recovery codes
7. Actions publicadas en app/Actions/Fortify/
app/Actions/Fortify/ ├── CreateNewUser.php ← registro (agrega campos extra aquí) ├── ResetUserPassword.php ← cambiar contraseña tras link de reset ├── UpdateUserPassword.php ← cambiar contraseña desde perfil └── UpdateUserProfileInformation.php
② spatie/laravel-one-time-passwords — OTP Email / SMS
1. Instalar

4. config/one-time-passwords.php

5. Flujo Passwordless Login
// PASO 1 — Solicitar OTP public function requestOtp(Request $request) { $user = User::where('email', $request->email)->firstOrFail(); $user->sendOneTimePassword(); return response()->json(['message' => 'Código enviado']); } // PASO 2 — Verificar OTP y loguear public function verifyOtp(Request $request) { $user = User::where('email', $request->email)->firstOrFail(); $result = $user->attemptLoginUsingOneTimePassword($request->code); if ($result->isOk()) { $request->session()->regenerate(); // ← SIEMPRE return response()->json(['redirect' => '/dashboard']); } return response()->json([ 'errors' => ['code' => $result->validationMessage()] ], 422); }
6. Soporte SMS con Vonage
./vendor/bin/sail composer require laravel/vonage-notification-channel class SmsOtpNotification extends OneTimePasswordNotification { public function via($notifiable): array { return ['vonage']; } public function toVonage($notifiable) { return (new VonageMessage()) ->content("Tu código: {$this->otp->password}"); } } // User model: public function routeNotificationForVonage(): string { return $this->phone_number; }
7. Scheduler — limpiar OTPs expirados (routes/console.php)
use Spatie\OneTimePasswords\Models\OneTimePassword; Schedule::command('model:prune', ['--model' => [OneTimePassword::class]])->daily();
③ Google Authenticator / TOTP — pragmarx/google2fa-laravel
Fortify ya incluye 2FA TOTP con QR para Google Authenticator (rutas /user/two-factor-*). Usa este paquete standalone solo si quieres un flujo 2FA propio fuera de Fortify (TOTP/HOTP RFC 6238/4226), generar tus QR y validar códigos manualmente.
1. Instalar (+ generador de QR)
./vendor/bin/sail composer require pragmarx/google2fa-laravel ./vendor/bin/sail composer require bacon/bacon-qr-code
2. Publish config + columna secret
./vendor/bin/sail artisan vendor:publish --provider="PragmaRX\Google2FALaravel\ServiceProvider" ./vendor/bin/sail artisan make:migration add_google2fa_secret_to_users // migration: $table->text('google2fa_secret')->nullable(); ./vendor/bin/sail artisan migrate
3. Activar 2FA — generar secret + QR
use PragmaRX\Google2FALaravel\Facade as Google2FA; $secret = Google2FA::generateSecretKey(); // 32 chars (v9+) $user->forceFill(['google2fa_secret' => $secret])->save(); $qrUrl = Google2FA::getQRCodeUrl( config('app.name'), $user->email, $secret ); // Renderiza $qrUrl como QR (BaconQrCode) en el SFC Vue
4. Verificar el código del Authenticator
public function verify(Request $request) { $valid = Google2FA::verifyKey( $request->user()->google2fa_secret, $request->input('otp') ); return $valid ? response()->json(['ok' => true]) : response()->json(['errors' => ['otp' => 'Código inválido']], 422); }
5. Middleware 2fa — proteger rutas
// bootstrap/app.php → withMiddleware: $middleware->alias([ '2fa' => PragmaRX\Google2FALaravel\Middleware::class, ]); // routes/web.php: Route::middleware(['auth', '2fa'])->group(function () { Route::get('/panel', PanelController::class); });
💡 Compatible con Google Authenticator, Authy, Microsoft Authenticator, 1Password, etc. (cualquier app TOTP estándar). El core pragmarx/google2fa se instala como dependencia.
④ Protecciones de seguridad incluidas
Fortify incluye: CSRF en todas las rutas · Rate limiting en login (5 intentos/min) · bcrypt automático · Session regeneration tras login · Remember me tokens seguros · Confirmación de password para acciones sensibles · Passkeys (Laravel 13)
Spatie OTP incluye: Expira en 2 minutos · Un solo uso · Valida IP y User-Agent · Máximo intentos configurable · Tabla separada de usuarios
Google2FA (TOTP) incluye: Compatible con Google Authenticator / Authy / Microsoft Authenticator · TOTP (RFC 6238) y HOTP (RFC 4226) · QR vía BaconQrCode · secret de 32 chars (160 bits, v9+) · middleware 2fa para proteger rutas.
⚠️ Error #1 con Fortify standalone: olvidar registrar FortifyServiceProvider en bootstrap/providers.php. Sin eso, ninguna ruta aparece.
💡 Verificar rutas: ./vendor/bin/sail artisan route:list | grep -E "login|register|password|two-factor"
⚡ WebSockets — Laravel Reverb
WebSockets
laravel/reverb + laravel-echo + pusher-js
Reverb ^1.0 · Oficial · 1st party
Servidor WebSocket oficial de Laravel. Compatible con el protocolo Pusher (Laravel Echo). Sin costos de terceros. Laravel 13 añade un driver de base de datos (sin Redis obligatorio).
Método recomendado — todo de una vez
./vendor/bin/sail artisan install:broadcasting # Elegir driver: reverb
Método manual
./vendor/bin/sail composer require laravel/reverb ./vendor/bin/sail artisan reverb:install ./vendor/bin/sail npm install laravel-echo pusher-js
Variables .env generadas
BROADCAST_CONNECTION=reverb REVERB_APP_ID=my-app-id REVERB_APP_KEY=my-app-key REVERB_APP_SECRET=my-app-secret REVERB_HOST="localhost" REVERB_PORT=8080 REVERB_SCHEME=http # Para Vite: VITE_REVERB_APP_KEY="${REVERB_APP_KEY}" VITE_REVERB_HOST="${REVERB_HOST}" VITE_REVERB_PORT="${REVERB_PORT}" VITE_REVERB_SCHEME="${REVERB_SCHEME}"
Echo en resources/js/echo.ts
import Echo from 'laravel-echo'; import Pusher from 'pusher-js'; window.Pusher = Pusher; window.Echo = new Echo({ broadcaster: 'reverb', key: import.meta.env.VITE_REVERB_APP_KEY, wsHost: import.meta.env.VITE_REVERB_HOST, wsPort: import.meta.env.VITE_REVERB_PORT, wssPort: import.meta.env.VITE_REVERB_PORT, forceTLS: (import.meta.env.VITE_REVERB_SCHEME ?? 'https') === 'https', enabledTransports: ['ws', 'wss'], });
Crear evento broadcast
./vendor/bin/sail artisan make:event OrderStatusUpdated class OrderStatusUpdated implements ShouldBroadcast { use InteractsWithSockets; public function __construct(public readonly Order $order) {} public function broadcastOn(): array { return [new PrivateChannel('orders.' . $this->order->id)]; } public function broadcastAs(): string { return 'order.updated'; } } // Disparar: broadcast(new OrderStatusUpdated($order))->toOthers();
Escuchar en Vue (<script setup lang="ts">)
const status = ref('pending'); let ch; onMounted(() => { ch = window.Echo .private(`orders.${props.orderId}`) .listen('.order.updated', (e) => { status.value = e.order.status; }); }); onUnmounted(() => ch?.stopListening('.order.updated'));
Correr en desarrollo
./vendor/bin/sail artisan reverb:start ./vendor/bin/sail artisan queue:work ./vendor/bin/sail npm run dev
Autorizar canales — routes/channels.php
Broadcast::channel('orders.{orderId}', function (User $user, int $orderId) { return Order::where('id', $orderId) ->where('user_id', $user->id)->exists(); }); // Canal de presencia (chat): Broadcast::channel('room.{roomId}', function (User $user, int $roomId) { if ($user->canJoinRoom($roomId)) { return ['id' => $user->id, 'name' => $user->name]; } });
Producción — Supervisor + Nginx
# /etc/supervisor/conf.d/reverb.conf [program:reverb] command=/usr/bin/php /var/www/app/artisan reverb:start autostart=true autorestart=true # Nginx — proxy WebSocket: location /app { proxy_pass http://127.0.0.1:8080; proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "Upgrade"; }
✅ Escalar: REVERB_SCALING_ENABLED=true + Redis — múltiples servidores coordinan automáticamente.

⚖️ ¿Laravel AI SDK vs FastAPI (Python)?
Criterio🟠 Laravel AI SDK🐍 FastAPI + Python
Integración app existente✔ Directo — mismo codebase⚠ Microservicio separado
Tiempo de setup✔ Minutos⚠ Horas (infra, Docker, API)
Agentes / tool calling✔ Nativo (clases Agent)✔ LangChain / frameworks
Ecosistema AI/ML profundo⚠ LLMs + embeddings + vector✔ PyTorch, HuggingFace, LangChain
Modelos custom / fine-tuning✗ No✔ Sí, total control
Streaming responses✔ SSE built-in✔ Soportado
Team PHP sin Python✔ Ideal✗ Curva de aprendizaje
Computer Vision / Audio / Video⚠ Imagen/audio vía providers✔ Librería madura
RAG / Vector DB✔ pgvector nativo + embeddings✔ LangChain, LlamaIndex nativos
✅ Usa Laravel AI SDK cuando: quieres chatbots, agentes, generación de contenido, resúmenes, clasificación, structured outputs o RAG dentro de tu app Laravel. Tu equipo es PHP. Elimina el microservicio Python en la mayoría de casos.
🐍 Usa FastAPI cuando: necesitas modelos custom, computer vision, NLP avanzado o fine-tuning. Ideal como microservicio AI que Laravel consume vía HTTP.
💡 Patrón híbrido: Laravel (AI SDK) para integraciones LLM y agentes + FastAPI solo para modelos ML pesados. Se comunican via REST API o colas.

Auto-extracción desde FormRequest (sin anotaciones)
class StoreTodoRequest extends FormRequest { public function rules(): array { return [ 'title' => ['required', 'string', 'max:120'], 'done' => ['boolean'], 'due_date' => ['nullable', 'date'], ]; } } // Scribe lee estas reglas y documenta cada parámetro.

/** * Crear una tarea * * @group Todos * @authenticated * @bodyParam title string required El título. Example: Comprar pan * @response 201 {"id": 1, "title": "Comprar pan"} */ public function store(StoreTodoRequest $request) { /* … */ }

./vendor/bin/sail artisan scribe:generate --force # openapi.yaml queda listo para Swagger UI, Redoc, etc.
✅ A diferencia de las herramientas que documentan en vivo, Scribe corre por comando (scribe:generate): puede invocar tus endpoints para obtener ejemplos de respuesta reales y entrega un HTML con "Try It Out". Totalmente gratis (MIT).
