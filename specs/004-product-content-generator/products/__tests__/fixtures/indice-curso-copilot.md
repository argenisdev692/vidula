## 🎓 Objetivos del Curso

- Entender cómo funciona GitHub Copilot e integrarlo eficazmente en VS Code y Visual Studio
- Aplicar técnicas de prompt engineering para mejorar las sugerencias en .NET y Angular
- Usar Copilot para crear y refactorizar proyectos fullstack, optimizando tiempo y calidad de código
- Integrar Copilot en flujos colaborativos y CI/CD, mejorando la productividad del equipo
- Evaluar productividad, seguridad y calidad del código generado por Copilot en proyectos reales

## 🛠️ Requisitos Previos

### Hardware
- CPU: Intel i5 o superior
- RAM: 8 GB (16 GB recomendado)
- Disco: 30 GB libres
- GPU (opcional): NVIDIA con 4 GB VRAM

### Software
- Visual Studio Code
- Visual Studio (actual)
- .NET SDK 8.0
- Node.js LTS (v18.x o superior)
- Git y Docker Desktop

### Cuentas y Licencias
- GitHub Copilot suscripción (versión más reciente)
- Acceso a repositorio Git compartido

### Experiencia
- Desarrollo y despliegue de aplicaciones web con C# y TypeScript en entornos .Net y Angular
- Zoom de escritorio instalado y configurado (cámara, micrófono, auriculares y 2 pantallas)

## 🚀 Inicio Rápido

1. **Clona el repositorio:**
    ```bash
    git clone https://bitbucket.org/virtual-sessions/curso-copilot.git
    cd curso-copilot
    ```

2. **Configura tu entorno:**
    - Revisa el `docs/indice-curso-copilot.md` para instrucciones detalladas
    - Instala las extensiones de VS Code necesarias (GitHub Copilot, etc.)
    - Verifica que tengas acceso a GitHub Copilot

3. **Comienza con la Sesión 1:**
    - Revisa `sesion1/README.md` para el contenido detallado
    - Configura tu entorno de desarrollo según las instrucciones
    - Consulta el temario completo en `recursos/indice-curso-completo.md`
